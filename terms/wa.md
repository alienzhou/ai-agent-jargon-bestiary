term: 挖
zh: ""
aliases: [深挖, 挖出来, 追查, 查清, digging]
category: 隐喻
kind: 代称
added: 2026-09-04
gloss: 不只看表面的说明，继续翻代码、配置或资料，把实际情况查出来。
actually: 挖通常就是「查」或「追到定义里确认」。在技术调研中，它暗示查的人越过了 README、示例配置这些表层材料，去看依赖声明、实现代码或运行条件；挖到了什么，仍要靠证据说话。
origin: 来自挖矿、考古和挖土：表面的东西看完后，继续往下才会露出埋着的东西。互联网语境先有「深挖」，技术汇报再把它缩成一个动作，配合「我挖了」宣告自己没有停在第一层搜索结果。
note: 「我看了依赖」很朴素；「我挖了扩展依赖」则让 package manifest 有了地层和矿脉。
usage:
  right:
    text: README 只写了 Postgres，我又挖了 migration 和 Dockerfile，确认还依赖 pgvector 扩展。
    why: 从公开说明继续查到具体实现和依赖，确实比扫一眼更往下。
  wrong:
    - text: 我家挖今天把沙发底下刨了个洞，晚上得给它剪指甲。
      why: 一只动物。它真正掌握了「从表面到深层」的方法论。
    - text: 中午点了一份挖，老板说这是本店招牌。
      why: 一道菜。上菜前需要先确认它的扩展依赖：筷子。
    - text: 这件挖穿起来很保暖，就是领口有点紧。
      why: 一件羽绒服。填充物越多，调研显得越深入。
    - text: 我把挖摆在阳台，每周浇一次水，它已经抽新芽了。
      why: 一盆植物。它不产出结论，只需要阳光。
