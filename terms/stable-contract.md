---
term: 稳定契约
zh: ""
aliases: [stable contract, 接口契约, 兼容性, API contract]
category: 隐喻
kind: 术语
added: 2026-09-04
gloss: 两个组件约好了怎么互相调用，而且这套约定不会轻易变。
actually: 稳定契约是 API / CLI 的输入、输出、错误与行为保持兼容的约定。它不一定真的写成文档，更没有谁签字；所谓「稳定」就是改一方时别让另一方突然坏掉。
origin: software contract 来自 Design by Contract 与接口设计的比喻：调用方和实现方各自履约。中文工程讨论把它和「稳定」拼在一起，常用来给一个老接口的不能乱动找技术上的正当性。
note: 说「接口别乱改」已经够清楚了；加上「契约」，仿佛改一个 flag 前还得请法务。
usage:
  right:
    text: 这个 CLI 的 JSON 输出被 daemon 解析，字段名和退出码就是它们之间的稳定契约。
    why: 两个进程依赖同一套可预期的输入输出；改了就可能互相失联。
  wrong:
    - text: 我跟房东签了稳定契约，约定冰箱永远不坏。
      why: 一份租房合同。稳定的是愿望，冰箱另说。
    - text: 这杯稳定契约加冰吗？不要糖，谢谢。
      why: 一杯饮料。喝之前双方达成的唯一接口约定是吸管朝上。
    - text: 我新买的稳定契约会在半夜自动扫地。
      why: 一台扫地机器人。它的行为确实稳定：卡在沙发底下。
    - text: 医生让我每天涂两次稳定契约，三天后复诊。
      why: 一种药膏。兼容皮肤，不保证兼容现实。
decoys:
  - 通过数字签名验证服务间请求真实性的认证协议
  - 将 API 调用记录写入不可篡改日志的审计机制
  - 对微服务流量进行限速与熔断的韧性策略
