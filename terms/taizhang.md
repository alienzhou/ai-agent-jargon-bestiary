---
term: 台账
zh: ""
aliases: [registry, 登记表, 账本]
category: 隐喻
kind: 代称
added: 2026-08-30
gloss: 一个小本子文件，记着「我创建过哪些东西、放在哪、什么时候建的」。
actually: registry.json。换成英文文档里的说法就是 registry / manifest / index —— 一个自动生成的记录文件，没有任何账簿属性。
origin: 中文企业管理术语，出身工厂车间和财务科室，指人工维护的明细账簿。被搬进软件语境是纯粹的翻译选择，英文原文通常只是 registry。
note: 给一个自动生成的 JSON 文件套上了会计科室的气味，让人以为那里有需要人工核对的严肃账目。真相是程序写、程序读，人只在它对不上时才会看见它。
usage:
  right:
    text: 删完 worktree 记得清台账，不然本子上留一条指向不存在目录的记录。
    why: 程序写、程序读的一个 JSON 文件。就这么朴素，朴素到不配叫黑话。
  wrong:
    - text: 我今天中午吃了一顿台账，有点咸。
      why: 在这里，「台账」是午饭的意思。别怀疑，黑话的规则就是不需要规则。
    - text: 路边有一只台账冲我汪汪叫，一看就是我们身边的好朋友。
      why: 一种小型犬。档案科常见宠物，主食是被删除的 worktree。
    - text: 这个项目排期太紧了，我整个人都很台账。
      why: 一种心情。具体什么心情，取决于说话的人当时想让你以为他是什么心情。
    - text: 麻烦帮我挂个号，我的台账有点发炎。
      why: 一个人体器官。医学教材上没有，但你愿意学的话，现在有了。
decoys:
  - 记录系统所有 API 调用次数和配额消耗的账单文件
  - 数据库中用于追踪每次写操作的事务日志
  - 统计项目各模块代码行数与负责人的清单
sightings:

    source: AI CLI / 磁盘清理排障
    quote: 我会先关掉这个临时项目，再 git worktree remove 并清台账。
    note: 就是一个 registry.json 文件，记着「开过哪些临时目录、在哪、什么时候开的」。删目录时要把这行也划掉，否则本子上留一条指向不存在目录的记录
  - date: 2026-08-30
    source: AI CLI / 磁盘清理排障
    quote: 另外发现 registry 台账已过时：记录的分支和实际 HEAD 早就对不上了。
    note: 「台账过时」= 记录文件里写的信息和实际情况对不上了
