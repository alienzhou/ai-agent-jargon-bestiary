# AI Agent 的黑话图鉴 / Jargon Bestiary

![AI Agent 的黑话图鉴](assets/cover.png)

> A living bestiary of AI agent jargon — translate the spell, reveal the creature.

「赋能」「对齐」「上下文工程」——AI 说的每个字你都认识，连起来就得想一下。你让它说人话，它态度很好，道歉，下一句照旧。

躲不掉的词，就把它搞清楚：每个词一张卡——人话翻译是什么、它其实是什么、在哪撞见的。一分钟认一个，AI 的输出读起来就不硌眼了。

至于为什么做成图鉴、每个分类配一只怪物、还开「遭遇战」考你谁用对了——给喷黑话的一方出一本正经图鉴，这件事本身就是答案。

## 玩

- 🎮 **图鉴 + 遭遇战** — 打开 [dist/index.html](dist/index.html)：单文件零依赖，双击就能玩
- 📦 **只要数据** — [dist/lexicon.json](dist/lexicon.json)：纯字段零 HTML，拿去做自己的页面
- 🪤 **撞见新黑话** — 把词丢过来：[飞书表单](https://my.feishu.cn/share/base/shrcn6SFjWEfb8FtclBBHIbYnpf)（GitHub 也能走 [Issue](https://github.com/alienzhou/ai-agent-jargon-bestiary/issues/new?template=submit-term.yml)）
